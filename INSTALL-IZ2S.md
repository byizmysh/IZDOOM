# IZDOOM 0.17.1 — установка в IZ2S

1. Установите и настройте [IZ2S Platform](https://github.com/byizmysh/IZ2S-Platform).
2. Скачайте из релиза **IZDOOM-v0.17.1-IZ2S.izm**.
3. В папке платформы создайте `modules/izdoom`, если её ещё нет.
4. Скопируйте скачанный пакет туда с именем **izdoom.izm**. Итоговый путь: `<папка IZ2S>/modules/izdoom/izdoom.izm`.
5. Откройте или обновите библиотеку приложений в панели IZ2S/IZ2W.
6. Выберите **IZDOOM** и загрузите модуль на подключённую консоль.
7. Откройте **IZDOOM** в меню на консоли.

Для готового `.izm` компиляторы и отдельные файлы данных не нужны: первый эпизод DOOM уже внутри пакета. При обновлении сначала выгрузите предыдущую копию IZDOOM из панели.

# IZ2S installation — English

1. Install and configure [IZ2S Platform](https://github.com/byizmysh/IZ2S-Platform).
2. Download **IZDOOM-v0.17.1-IZ2S.izm** from this release.
3. Create `modules/izdoom` inside the platform installation if needed.
4. Copy the download there as **izdoom.izm**: `<IZ2S folder>/modules/izdoom/izdoom.izm`.
5. Open or refresh the platform's app library, select **IZDOOM** and load it onto your connected console.
6. Open **IZDOOM** in the console launcher.

The ready-to-load package includes the episode-one game data. No compiler or separate data file is needed. Unload an existing copy before replacing its package.

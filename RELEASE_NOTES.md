# IZDOOM v0.17.1

Homebrew port of DOOM for NS2 (Nintendo Switch 2), running through IZ2W / IZ2S Platform.

- Full textures, original sprites/HUD and smoother GPU level transitions.
- Includes signed movement fixes and 20% lower analog movement/turn sensitivity.
- Removes the central crosshair.
- Adds the IZDOOM icon with a small IZMYSH credit.
- Sound effects and music are not yet implemented. No host audio service or BlitBun dependency.
- Complete corresponding source, pinned upstream, patch and offline build tools included.

Requires IZ2W / IZ2S Platform and a separately supplied DOOM1.WAD. Public assets contain source only; game data is not included.
